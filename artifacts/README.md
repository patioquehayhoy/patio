# Artifacts

- `patio-sistema.html`: el documento único de Patio. Tres partes: Marca
  (brand book), Producto (pantallas y flujos) y Piezas (inventario con
  estado). Ábrelo en Chrome; se navega con las flechas del teclado y la
  vista de todas las páginas.
- `img/`: la P en negro, en blanco y como ícono, que usa el documento.

Las fuentes de prueba (Monument y Neue Montreal) se cargan desde
`assets/fonts/prueba/`, fuera de Git: el documento solo se ve completo en
la Mac que las tiene.
