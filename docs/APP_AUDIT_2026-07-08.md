# Patio app audit - 2026-07-08

## Conclusion ejecutiva

La app no tiene un bloqueo evidente de compilacion, lint o bundle. TypeScript pasa, ESLint pasa, y Expo exporta correctamente para iOS y Android.

Lo que si queda abierto no es de "codigo no compila", sino de validacion real en dispositivo y configuracion externa: magic link con Supabase, permisos de camara/galeria/GPS, vision IA, compartir posters, push notifications y deep links.

## Validado hoy

- `npm run typecheck`: pasa.
- `npm run lint`: pasa.
- `npx expo export --platform ios --output-dir /tmp/patio-audit-export`: pasa.
- `npx expo export --platform android --output-dir /tmp/patio-audit-export-android`: pasa.
- Rutas principales en `app/`: existen y no hay navegaciones obvias hacia pantallas inexistentes.
- Separacion de controllers: las pantallas principales ya no concentran toda la logica de negocio en el archivo visual.

## Problemas confirmados

### P0 - Riesgo de produccion

- `lib/vision.ts` usa Anthropic desde cliente con `EXPO_PUBLIC_ANTHROPIC_API_KEY` y `dangerouslyAllowBrowser: true`.
  - Esto puede exponer costos, abuso de API y llaves publicas.
  - Para demo/prototipo puede servir, pero antes de produccion debe moverse a backend, Edge Function o proxy controlado.

### P1 - Salud Expo

`npx expo-doctor` falla 2 checks:

- `@types/react-native` esta instalado directamente y Expo recomienda no instalarlo.
- Paquetes Expo tienen patch versions atrasadas:
  - `expo`: esperado `~54.0.35`, actual `54.0.33`
  - `expo-dev-client`: esperado `~6.0.21`, actual `6.0.20`
  - `expo-file-system`: esperado `~19.0.23`, actual `19.0.21`
  - `expo-font`: esperado `~14.0.12`, actual `14.0.11`
  - `expo-image-picker`: esperado `~17.0.11`, actual `17.0.10`
  - `expo-linking`: esperado `~8.0.12`, actual `8.0.11`
  - `expo-router`: esperado `~6.0.24`, actual `6.0.23`
  - `expo-web-browser`: esperado `~15.0.11`, actual `15.0.10`

Accion recomendada:

```bash
npx expo install --check
```

Despues remover `@types/react-native` si sigue listado como dependencia directa.

### P1 - Limpieza de rutas

- Existe `app/.perfil.tsx.swp`.
- No rompio el export, pero vive dentro de `app/` y puede confundir a Expo Router o a herramientas futuras.
- Accion recomendada: borrar ese archivo temporal cuando se confirme que no contiene trabajo pendiente.

## Por validar en iPhone / entorno real

Estas partes no se pueden dar por sanas solo con typecheck/export:

- Magic link completo:
  - Supabase debe permitir `patio://login-callback`.
  - Validar que `app/login-callback.tsx` reciba code/token y redirija bien.
- Camara y galeria:
  - `expo-image-picker` debe abrir, pedir permisos y entregar imagen valida.
- Lectura de menu con IA:
  - Validar imagen real, latencia, errores de API y resultado editado.
- GPS:
  - Validar permiso y guardado de coordenadas en perfil/patio.
- Compartir poster:
  - Validar `view-shot`, archivos temporales y `expo-sharing`.
- Push/local notifications:
  - Validar registro/permisos y fallback si no esta disponible.
- Abrir mapas:
  - Validar Apple Maps/Google Maps desde detalle de patio.
