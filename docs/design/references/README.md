# Referencias visuales — Patio

Esta carpeta es la fuente oficial de screenshots de estilo.

## Dónde pegar tus imágenes

Pon cada screenshot aquí:
- `docs/design/references/`

Formato sugerido de nombre (v1):
- `categoria_objetivo_fuente_vNN.png`
- Ejemplo: `botones_cta_apple-hig_v01.png`
- Ejemplo: `tipografia_editorial_kometa-stabil_v02.png`
- Ejemplo: `interfaz-completa_home_uber_v03.png`

Si quieres guardar evolución por sesiones:
- `YYYY-MM-DD_categoria_objetivo_vNN.png`
- Ejemplo: `2026-04-27_share_layout_v04.png`

## Registro obligatorio (index)

Cada imagen que agregues, anótala en `STYLE_INDEX.md` con:
- archivo
- fuente (app/sitio)
- qué nos gustó
- dónde se aplicará en Patio

## Importante

No borrar referencias anteriores: solo agregar nuevas versiones.
Los metadatos se pueden perder al exportar o reenviar; por eso la versión en nombre es obligatoria.
